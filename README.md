# About

Rube-Goldberg-Portfolio is a big, seemingly useless app that sums up most of what I can use to develop. Because 
recruiters, eh!

The idea is to use all... well as many technologies as I've worked with. The reasons are:
- When prepping for an interview, I can use this project to refresh my memory and play around.
- When upgrading language or framework versions I can use this to learn the new features.
- When someone tells me "riiight but you haven't worked with Angular for the past year, we can't hire you" I can at 
	least bring this as an argument.
- I like developing for fun!
