This application is using:

- PostgreSQL 19 RC 1 in a docker container using image postgres:19rc1-trixie
- Spring Boot with:
  - Data JPA
  - Docker Compose (to start the Postgres docker)
  - Web
- React with
  - React Router
  - React Bootstrap
- OpenAPI 3.2
- Springdoc OpenAPI

Just play around and have fun!
